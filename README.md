# PPT

특성화고 진로진학상담의 기법과 전략을 웹 프레젠테이션으로 재구성한 프로젝트입니다.

## 보기

`index.html`을 브라우저에서 열면 됩니다. 별도의 설치나 인터넷 연결이 필요하지 않습니다.

- 스크롤형 프레젠테이션
- 발표 모드와 방향키 탐색
- 17장 전체 목차
- 반응형 모바일 레이아웃
- 모집요강 근거 이미지 확대
- 모션 감소 설정 지원

`특성화고_진로진학상담.html`은 이미지와 폰트를 포함한 단일 파일 배포본입니다.

## 수정 및 패키징

콘텐츠와 동작은 `index.html`, 디자인은 `design-v2.css`에서 수정합니다. 수정 후 다음 명령으로 단일 파일 배포본을 다시 만듭니다.

```powershell
python package-html.py
```

표지 이미지는 이미지 생성 도구로 제작했습니다. 사용한 프롬프트와 디자인 결정은 `DESIGN-NOTES.md`에 기록되어 있습니다.

## 폰트

Pretendard Regular와 SemiBold를 포함합니다. 라이선스 전문은 `assets/Pretendard-LICENSE.txt`에서 확인할 수 있습니다.
